# My Staff · Моя коллекция

[English](README.md) · **Русский**

Приложение для коллекционирования банок энергетиков и тубусов Pringles: фотография превращается в личную карточку, а оригинал сохраняется вместе с предметом.

> [!IMPORTANT]
> **Проект в активной разработке, версия 0.2.0 alpha.** Рабочий Android-прототип проверен на эмуляторе; замечания с Android-тестирования собраны в issue №6. Проверка исправлений на настоящем S24 Ultra и iOS ещё впереди. Автоматическое распознавание и студийное оформление выключены по умолчанию. Публичного сервера и версии в магазине пока нет.

## Что работает

- Камера и импорт фотографии; дополнительные ракурсы.
- Отдельные категории энергетиков и Pringles, поиск, фильтры и заметки.
- Карточка с лицевой стороной и оригиналом на обороте.
- Локальные оригиналы и SQLite, очередь отправки и восстановление прерванного сохранения.
- Вход, синхронизация с собственным сервером, проверка целостности фотографий.
- Удаление с восстановлением, ZIP-экспорт и повторный импорт без дубликатов в той же коллекции.
- Каталог изданий и предложения пользователя, редакторские API подтверждения и объединения.

Редкость и социальные механики отложены: приоритет — надёжное хранение коллекции и правильная модель предметов.

## Попробовать

[Скачать APK и контрольную сумму из предварительного релиза](https://github.com/realfamousbae/my-staff/releases/tag/v0.2.0-alpha.1).

В версии 0.2 приложение называется My Staff и получило иконку «М» на фиолетовом фоне. Системная кнопка «Назад» возвращает к предыдущему экрану, дополнительные фото доступны в галерее карточки, а импорт работает и без доступа к камере.

ARM64 APK работает без Metro, Expo Go, аккаунта и AI-ключа. Для синхронизации нужен свой запущенный сервер. Сборка подписана тестовым ключом и предназначена для личной проверки.

```sh
git clone https://github.com/realfamousbae/my-staff.git
cd my-staff
pnpm install --frozen-lockfile
pnpm setup:local
pnpm dev:backend
```

Требуются Node.js 22, pnpm 10.34.5 и запущенный Docker с Compose. Для разработки клиента в другом терминале: `pnpm dev:mobile`. Подробности — в [инструкции запуска](docs/getting-started.md).

Для эмулятора адрес API — `http://10.0.2.2:3000`. Для телефона по USB:

```sh
adb reverse tcp:3000 tcp:3000
adb install -r artifacts/my-collection-android.apk
```

В настройках приложения укажите `http://127.0.0.1:3000`. В примере APK предварительно скачан в каталог `artifacts/`. Для удалённого API нужен HTTPS.

## Ограничения alpha

Один ZIP ограничен 200 МБ; полноценный перенос большой коллекции потребует потоковых или многотомных архивов. Фоновая отправка при закрытом приложении пока не реализована. Нет восстановления пароля, подтверждения почты, редакторской панели, публичного размещения и проверки iOS. Реальные AI-вызовы и качество распознавания на коллекционных упаковках ещё не проверялись.

Без AI карточка использует настоящее исходное фото, а издание выбирается вручную. Синхронизация не заменяет резервную копию. Удаление приложения удаляет его локальные данные.
